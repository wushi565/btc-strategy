# 比特币交易策略系统 - 整合优化版

一个整合传统技术分析和机器学习的比特币交易策略系统，专注于高性能和模块化设计。

## ✨ 主要特点

### 📈 传统交易策略
- **Supertrend 指标**：跟踪价格趋势变化
- **DEMA (双指数移动平均线)**：144 和 169 周期
- **智能止损止盈**：基于风险回报比的自动平仓
- **ADX 趋势强度过滤**：避免震荡市场的假信号

### 🧠 机器学习增强
- **多模型集成**：随机森林、XGBoost、LightGBM模型
- **自动特征工程**：120+个交易特征
- **信号置信度评分**：衡量信号可靠性
- **在线学习**：根据新数据持续优化

### 🚀 性能优化
- **向量化计算**：使用 NumPy 和 Pandas 优化性能
- **智能缓存**：避免重复计算，显著提升速度
- **内存优化**：减少内存占用，处理大数据集
- **批处理**：批量计算所有技术指标

### 💾 数据管理
- **多数据源支持**：币安 API / 本地文件 / CSV 导入
- **自动缓存**：历史数据本地存储，避免重复下载
- **代理支持**：支持HTTP/SOCKS5代理访问
- **时区处理**：自动处理不同时区的时间数据

### 🔄 系统集成
- **模块化架构**：组件高内聚低耦合
- **灵活配置**：通过YAML配置所有系统参数
- **统一接口**：整合传统和ML系统的接口
- **混合信号**：可组合使用技术信号和ML信号

## 🔧 安装配置

### 环境要求
- Python 3.8+
- 推荐使用 conda 或 venv 虚拟环境

### 依赖安装
```bash
pip install -r requirements.txt
```

### 配置文件
系统使用 `config.yaml` 进行配置：

```bash
# 如果没有配置文件，复制默认配置
cp config_default.yaml config.yaml
```

编辑 `config.yaml` 以配置系统参数：

```yaml
# 启用/禁用机器学习增强
enable_ml: true

# 交易参数
trading:
  symbol: "BTC/USDT"
  timeframe: "1h"
  is_futures: true

# 技术指标参数
indicators:
  dema144_len: 144
  dema169_len: 169
  atr_period: 34
  atr_multiplier: 3.0

# 更多参数请参考config_default.yaml
```

## 📊 策略逻辑

### 传统策略
1. **买入条件**：
   - Supertrend 指标由空转多（趋势反转）
   - 价格突破 DEMA144 和 DEMA169 均线
   - 可选：ADX > 阈值（过滤弱趋势）

2. **卖出条件**：
   - Supertrend 指标由多转空（趋势反转）
   - 价格跌破 DEMA144 和 DEMA169 均线
   - 可选：ADX > 阈值（过滤弱趋势）

### 机器学习增强
1. **特征工程**：
   - 价格模式特征
   - 技术指标特征
   - 交易量特征
   - 波动率特征
   - 时序特征
   - 动量特征
   - 统计特征

2. **信号生成**：
   - 预测未来价格方向
   - 计算信号置信度
   - 根据置信度过滤信号

3. **系统集成**：
   - 综合传统信号和ML信号
   - 根据置信度动态调整权重
   - 只在置信度高时执行交易


调整机器学习模型的参数：


## 🔍 常见问题

### 数据获取问题
- **问题**：无法从交易所获取数据
- **解决方案**：
  - 检查网络连接
  - 启用代理设置 (`network.enable_proxy: true`)
  - 使用本地数据文件

### 机器学习问题
- **问题**：ML模型性能不佳
- **解决方案**：
  - 确保训练数据足够（至少1000条记录）
  - 调整 `ml_signal_enhancer` 中的特征参数
  - 增加训练数据的时间范围

### 性能问题
- **问题**：处理大量数据时系统变慢
- **解决方案**：
  - 减少回测数据量
  - 启用内存优化选项
  - 使用优化的向量化方法
